# Into the Grid – OOP Simulation

This program simulates a cyberpunk world of hackers, rigs and digital assets.  
It was created for the COMP 1048 Object Oriented Programming course (SP6 2025).

## Files
- **Asset.py** – Defines the Asset class used to represent digital items that can be encrypted, decrypted, or transferred.  
- **Rig.py** – Defines the Rig class that stores assets, takes damage, repairs, upgrades, and generates new assets.  
- **Hacker.py** – Defines the Hacker class that manages rigs, performs attacks, encrypts assets, and handles trace levels.  
- **Main.py** – Runs grouped test sections demonstrating battles, upgrades, encryption, repairs, and edge cases.

## How to Run
Run `main.py` to test all program features.  
Each test prints results to the console to verify expected behaviour.
